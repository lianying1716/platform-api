# 星采 Stargather · Logo 重设计简报（Design Brief）

> 由 `logo-design` 技能按发现流程产出，作为本轮生图方向的对齐基线。
> 生成日期：2026-10-09

## Summary（一句话）
**星采 / Stargather** 是给中文自媒体创作者的自动化素材采集与管理加工平台：
把 B站/抖音/小红书/快手/知乎 的抓取、下载、转录、AI 分析收敛进一个工作台，
让创作者稳定产出可用素材。

## Audience（用户人群）
- **主**：全职 / 半职业自媒体创作者、内容运营、一个人干一整个「内容流水线」的独立创作者
  （B站 UP、抖音/小红书博主、口播/知识类作者）。年龄偏 20–35，天天泡在后台，重效率、怕花哨。
- **次**：技术型玩家 / 用 AI 批量做内容的团队，会手动挂任务、看数据。
- **在哪遇见它**：浏览器标签 favicon、工作台侧栏、登录页、app 图标、深色侧栏、README 头部。

## Brand adjectives（品牌调性）
**精确 · 克制 · 有力量 · 工具感 · 可靠**（硬朗但不冰冷；像一件称手的工具，不是玩具）
**Avoid feeling**：可爱 · 花哨 · 潦草 · SaaS 渐变紫 · 素材站土味

## Promise / big idea
兜住所有平台、所有账号、所有素材：**把散落的星一颗颗收进轨道**（散乱 → 秩序）。

## 现有资产与要保留的部分
- 视觉系统已定 **V3 包豪斯**（`web/src/styles/tokens.css`）：纯几何、硬边、零圆角、零渐变。
- 品牌色：**砖红 `#CC2823`**（强调）、**墨 `#1A1512`**（主色）、**米白 `#F3F0E7`**（底）、蓝 `#0B58BB`（辅助）。
- 名称含「星」（Star），英文 Stargather —— **「收拢 / 采集 / 入轨」** 是可保留的语义。
- 现行「轨道 Orbit」几何偏细碎，缩到 16px 会退化成「红圈套黑点」，已被判定太丑，需重做。

## Competitive landscape（品类视觉，需避开）
- 素材/采集/AI 工具类满屏是：**四角星、魔法棒、机器人头、上传箭头、渐变色块** —— 全部视为陈词滥调。
- 邻近工具（Feishu/Notion/n8n/影刀/Coze）多用：字母标记、极简几何块、单一高饱和色。
- **空白区**：包豪斯式「结构感几何 ＋ 砖红单一强调色 ＋ 挤进 16px 仍成立的强剪影」，
  用**「采集 / 汇聚 / 入轨」的动作隐喻**，而不是又一颗四角星。

## Mark type hypothesis（标志类型假设）
生成阶段优先探索**抽象标记 + 几何负空间**（≤2 色 + 底色），备选**字母图形（S / 采 / 星）**。
纯字母无变化（stock letter）不可接受；不做拟物、不做徽章、不做吉祥物。

## Must work on
favicon 16px、侧栏 24px、app 图标 512、深色侧栏反白、单色（纯黑/纯白）、打印。

## Constraints
硬边、无渐变、无阴影、无 3D、无描边文字、根目录不出现文字（位图阶段只做 symbol），
只用品牌四色，背景纯色。产物是**位图候选**，选定后须重绘为精确 SVG 母版再交付全套资产。

## Assumptions（我做的假设，可纠正）
1. 允许继续用「星 / 收拢 / 轨道」这条语义线，但形式必须换新、更整块、更狠。
2. 名称「星采 / Stargather」与四色令牌不变。
3. 本轮只要**符号（symbol）**，锁定后再做横版组合与字标。
