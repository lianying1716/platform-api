# 星采 · 生图 logo 候选（第一版）

用星算 `gpt-image-2` / `gpt-image-2.5` 生成，共 4 轮 24 款。

## 在线看（局域网）

```
http://127.0.0.1:9100/brand/logo-gallery.html
```

一页看完 20 款（含 64/32/16px 缩放与深底反白测试），按视觉模型评审分排序，红框为最高分三款。

## 工作流（关键：本环境无法直接看图）

1. **生成**：调星算 `POST /v1/images/generations`，返回图片 URL 后 `curl` 下载。
   （官方 imagegen CLI 不兼容：它读 `b64_json`，星算返回的是 URL。）
2. **评审**：把图 base64 发给星算上的视觉模型（`qwen3.8-flash`），按品牌设计标准逐张打分。
3. **小尺寸验证**：把图缩到 16px 再放大 16 倍，交给视觉模型判断是否还认得出。
4. 三者结合替代肉眼。

## 四轮迭代与结论

| 轮次 | 模型 | 思路 | 结果 |
|---|---|---|---|
| 1 | gpt-image-2 | 直接在四角星周围加几何：箭头汇聚 / 取景框 / 托盘 / 叠层 / 轨道 / 碎片 | 最好 7 分（取景框）。评审指出**「四角星」本身就是烂大街的 AI/素材类符号** |
| 2 | gpt-image-2 | 绕开星形，纯几何：梳齿 / 叠层 / 折角 / 菱切 / 门框 / 风车 | **7.5 分（菱切）**，唯一被评为「不像现成模板」。但纯几何容易读成通用图标 |
| 3 | gpt-image-2 | 从汉字「采」的结构取形（手在树上采摘） | 最好 6 分。有独特性，但小尺寸粘连、语义弱 |
| 4 | gpt-image-2.5 | 强艺术指导：碎片成星 / 负空间星 / 抓取 / X 采 / 溢出 / 三芒 | **7 分（负空间星）**，16px 实测强 |

## 评审最高分（推荐先看这三款）

| 编号 | 名称 | 分数 | 说明 | 16px 实测 |
|---|---|---|---|---|
| **D** | 菱切 | 7.5 | 大菱形被一条竖缝切成左右两块，不对称 | 能辨认，读作「钻石/菱形」 |
| **H** | 负空间星 | 7.0 | 实心方块挖出四角星，下角刺破底边 | 能辨认，读作「准星」，对比强 |
| **B** | 取景框 | 7.0 | 四角取景框锁定中心星 | 能辨认，读作「对焦/取景框」 |

> 三款的 16px 表现均经视觉模型实测确认可辨认。

# 第 3 轮重设计（2026-10-09）· 由 logo-design 简报驱动

用户反馈现行「轨道 Orbit」太丑。按 `logo-design` 技能的发现流程重做：先出**设计简报**再生成，
不再凭空画。本轮只做**符号（symbol）**，产物是 image2.5 位图概念稿，选定后重绘为 SVG 母版。

## 步骤

1. **简报** `BRIEF.md`（Summary / 用户人群 / 品牌调性 / 空白区 / 类型假设 / 约束 / 假设）
2. **生成** 用星算 `gpt-image-2.5`（= 用户口中的 image2.5），3 轮 13 款
   - 第 1 轮 `prompts6.py` → `raw6/`（6 款：三向汇聚 / 入坞 / 环上芯片）
   - 第 2 轮 `prompts7.py` → `raw7/`（4 款：修正入坞 + 彗尾收拢 / 汇入菱形 / S 字母）
   - 第 3 轮 `prompts8.py` → `raw8/`（3 款：入坞加节点 / S 嵌瓷砖 / 采集托槽）
3. **评审** `see.py` 把每张发给视觉模型打分（本环境无肉眼，用视觉模型当眼睛）

## 评审结论

| 编号 | 名称 | 分 | 结论 |
|---|---|---|---|
| **I** | S 嵌入字母 | 7 | 专属度最高，读作专属 S；红色间距缩小需放宽 |
| **J** | 采集托槽 | 7 | 16px 最强、轮廓最干净；隐喻偏通用「收集」 |
| **D** | 入坞 | 7 | 骨架有力；红点有被读成「通知角标」的风险 |
| **G** | S 字母 | 7 | 读作 S；下滑缝 16px 会粘连 |
| F | 汇入菱形 | 6 | 「采集」语义明确；拖尾 16px 会糊 |
| H | 圆方入坞 | 6 | 外圆内方有铜钱联想，方孔 16px 丢失 |
| E | 彗尾收拢 | 6 | 16px 强，但等于通用「彗星」符号 |
| B/C | 缺口方坯 / 环上芯片 | 6 | 几何母题偏常见、无星采语义锚点 |

# 第 4 轮（2026-10-09）· 换方向：按「星采 = 采星」重做

用户反馈：第 3 轮的几何方向「与期望不符」，且 **logo 与 UI 设计是两件事，不该混同**。
明确需求：① 汉字字标「星采」+ ②「采星」意象符号，气质要 **星空 / 诗意 / 浪漫**。

## 结论（先说结果）

**汉字字标方向胜出**：`a1` / `a2` 两版均 **8/10**，且视觉模型**逐字核对为「星采」无误**。
两个符号方向（意象符号 / 星空诗意）反复被视觉模型判为「通用图标 / emoji」，分数 4-7，均未过线。

| 方向 | 编号 | 名称 | 分 | 结论 |
|---|---|---|---|---|
| ① 汉字字标 | **A1** | 衬线字标（星字内嵌星芒） | **8** | 首选 |
| ① 汉字字标 | **A2** | 现代字标（星顶一枚红星） | **8** | 并列首选 |
| ② 意象符号 | B1 | 手捧星 | 7 | 「采星」叙事最好，但偏 emoji 手托星 |
| ② 意象符号 | B3/B4 | 托举弧 / 开口兜 | 5 | 16px 强，但读成夜间模式 / 皇冠星标 |
| ③ 星空符号 | C1-C4 | 星群 / 北斗舀星 / 弧拢光 / 星轨 | 4-5 | 视觉模型反复判为「通用 / emoji」 |

**被否决的教训（诚实记录）**：`a3` 小尺寸粗体字标把「星」生成成了 **「皇」**（错字），得 1 分直接废弃。
→ 生图模型写汉字不稳定，**字标最终必须由人重绘字形**，不能直接采用位图。

# 第 5 轮（2026-10-09）· 放松提示词后重生成

用户指出：第 3、4 轮的 COMMON 约束太严（几十条否定 + 硬编码 hex + 强制平面色块/16px 必认），
把 image2.5 的设计能力压死了，出来的标志僵硬、奇怪。要求：**修改提示词、别做太严格限制、讲清用途**。

## 改了什么

- **删掉**整段否定清单（no gradient / no glow / no 3D / no shadow / no dots...）与硬编码 hex。
- **改成讲品牌故事**：星采 = 采星；受众 = 20-35 岁中文独立创作者；气质 = 星空/诗意/浪漫/精致。
- **明确用途**（用户要求重点）：产品内品牌标 / 手机 APP 图标 / favicon / 登录页 / 印刷周边，需大小兼顾；
  调色只给「建议」而非强制。
- 放开让模型自己决定：做字标、符号还是组合。

## 结果：明显变好

上一轮 8 分只有 2 款（都是字标，符号方向全灭 4-5）。本轮 6 款里 4 款 ≥7、符号方向也出到 8 分。

| 编号 | 名称 | 分 | 结论 |
|---|---|---|---|
| **M3** | 诗意符号 · 月碗托星 | **8** | 设计感/原创性评为「强」，未落入 emoji 俗套；概念与调性最佳 |
| M4 | 符号 + 中文字标（组合） | 7 | 圆盘星芒 + 轨道 + 星采字标，规整；冷暖色需统一 |
| M2 | 汉字字标 · 宋体变体 | 7 | 星/采 正确、星意入笔画；骨架偏常规 |
| M5 | 星轨圆盘 · 夜空 | 7 | 奶油底 + 墨蓝夜空 + 金轨，温柔；「采」字红点粘连 |
| M6 | 印章 / 东方徽标 | 6 | 东方气，但图形内「星」字破形 |
| M1 | 星球星轨 + 字标 | 5 | 氛围强但元素过多、中心偏乱 |

共同待修：多为**多色/带光影**版本，16-24px 会糊 → 落地需要各配一套**单色极简版**当 favicon / app icon。

## 已产出

- `m3/README.md` —— 选型说明、配色、资产清单、**重要限制**
- `m3/OVERVIEW.png` —— 资产总览（母本 + 尺寸阶梯 + favicon）
- `m3/dist/` —— 全套位图：`full-lockup.png`、`symbol-{1024..16}.png`、
  `favicon.ico`、`apple-touch-icon.png`、`maskable-512.png`
- `platform-api/web/public/brand/m3/` —— 网页副本
- `m3/_DRAFT-vector-redraw.svg` —— 自动重绘草稿（标注「勿用作母版」）
- `logo-gen/m3_assets.py` —— 资产导出脚本

## 诚实结论：矢量母版未完成

花了几轮尝试把这张概念图转成可投产矢量，**都没达到标准**：

| 方法 | 结果 |
|---|---|
| vtracer 自动描摹（多组参数 / 分层 / 4 色量化） | 边缘毛刺，丢失光晕与渐变，2–5 分 |
| 两圆几何拟合碗形 | IoU 仅 0.78；原图是「扭转飘带」，非简单月牙，4 分 |
| 分层描摹（浅色层 + 红色层） | 碗变实心块，中心星变形，2 分 |

根因：M3 是**带渐变与颗粒质感的立体渲染图**，不是扁平几何图形。自动矢量化天然处理不了。

**因此**：当前交付是**位图资产**（可直接用于网页 / favicon / App 图标 / 印刷打样）；
印刷级矢量（SVG/AI/EPS）建议**人工照母本重绘**。

## 小尺寸提醒

该标志细节多（光晕 + 多颗星），**32px 以下辨识度骤降，16px 退化为亮斑**。
若需要 favicon 级别的极小尺寸，建议另做一个简化版（只保留「碗 + 一颗中央星」）。
