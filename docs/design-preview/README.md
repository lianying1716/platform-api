## 三个方向分别是什么

### A · 暖石 Atelier（暖中性纸感 + 赭石强调）
- 场景：白天办公室，长时间看内容列表；希望界面安静，让**素材本身**出彩。
- 特点：暖白底、赭石橙作为唯一强调色（≤10%）、圆角 10–14px、卡片有轻微投影。
- 适合：内容创作者 / 运营，观感亲和、不刺眼。

### B · 控制台 Console（冷石板 + 青绿强调，密度更高）
- 场景：运营盯盘，一屏看更多行，数字对齐、状态一眼可辨。
- 特点：冷灰蓝中性、青绿强调、圆角 7–10px、表格更紧凑、数字用等宽对齐。
- 适合：数据量大的看板 / 队列，专业、克制。

### C · 刊物 Editorial（近白 + 深墨绿，靠排版而非卡片）
- 场景：以阅读/审阅为主，弱化容器、强化层级，像一份内容简报。
- 特点：几乎无投影、细分割线、圆角 3–5px、侧栏也用浅色、字距更讲究。
- 适合：偏阅读与报告的场景，安静、有编辑感。

## 三者共同的改动（无论选哪个都会做）

1. **一套设计令牌**（`web/src/styles/tokens.css`）：颜色 / 字号 / 间距 / 圆角 / 阴影，并用
   `--el-*` 桥接 Element Plus，保证全站一致。
2. **可读性**：正文 14px、行高 1.6；表格数字等宽对齐；状态用「色点 + 徽标」而非纯文字。
3. **去掉默认蓝**：强调色只用于主操作 / 当前选中 / 状态，不做装饰。
4. **空态 / 加载骨架 / 错误提示**统一文案与样式。
5. **响应式**：窄屏折叠侧栏、表格横向滚动。

## 反规范（都不会出现）
- 左侧色条（side-stripe）、渐变文字、玻璃拟态、大数字英雄模板、一模一样的卡片墙。
