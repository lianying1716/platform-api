## 三个方向分别是什么

这不只是换配色，**布局范式**也不同：

### V1 · 瑞士排版 Grotesk
- **没有侧栏**：导航压成顶部一条「目录带」，整屏还给数据版式。
- 近白纸底 + 单一电蓝强调；圆角 2px、无投影、细分隔线；表头全大写。
- 强调靠**网格与字重**分层，几乎不用卡片。指标区是一整块用 1px 线切开的矩阵。
- 适合：大屏、白天、内容审阅，冷静专业。

### V2 · 深夜控制台 Nocturne
- 左侧固定深色栏；近黑蓝底 + 青绿**发光**强调；数字全部等宽。
- 状态点、开关、主按钮带辉光；图表是主角，网格线压到最低。
- 适合：暗光房间盯盘、7×24 跑队列，有"仪表盘"的现场感。

### V3 · 包豪斯 Bauhaus
- 左侧深色栏 + 顶部 6px 粗黑边；暖米白底 + 砖红强调 + 蓝/黄辅助。
- **硬边**：全站 0 圆角、2px 实线边框、`3px 3px 0` 偏移硬阴影，悬停还会"抬纸"。
- 表头/卡片底边用粗线，像一册印刷品。
- 适合：想要强个性、辨识度高的品牌感。

## 图表现已覆盖的类型（真实 ECharts，非图片）

总览页：折线（dataZoom + 图例切换 + 十字准星）、环形占比、散点四象限（markLine 中位线）、迷你走势 sparkline。

数据看板页：**brush 框选联动**（上图框选 → 下图过滤）。

「组件与图表」页：热力图、漏斗、雷达、日历热力、桑基（节点可拖拽）、仪表盘，并按类型分段筛选。

技术栈：Apache ECharts 6 + vue-echarts，按需注册控制体积；图表颜色从当前方向的设计令牌读取，换方向即换图表配色。

---

## 三者共同的改动（无论选哪个都会做）

1. 设计令牌层（颜色/字号/间距/圆角/阴影 + `--el-*` 桥接），彻底改掉 Element Plus 默认观感。
2. 自建组件层：按钮（default/hover/focus/active/disabled/loading）、分段控件、徽标、开关、面板、表格、骨架屏、空态、toast。
3. 每个交互控件补齐全部状态，杜绝"点了没反应"。
4. 图表统一走 `components/charts/*`，不再各页各写一套。

## 敲定后我会怎么落地

1. 你选一个方向（或指定"V2 的布局 + V3 的硬阴影"这类混搭）。
2. 把该方向的令牌设为默认（`data-dir` 去掉，直接落到 `:root`）。
3. 组件层抽成 `components/ui/*`，逐页替换：总览 → 数据看板 → 关注博主 → 关键词采集 → 订阅同步 → 素材库 → 处理队列 → 账号中心 → 设置。
4. 每页替换后跑构建 + 浏览器回归，确认按钮全部可用。
5. 移除本预览页（`/design-preview`）与顶部切换条。
