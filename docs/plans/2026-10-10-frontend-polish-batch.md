## 0. 总原则

- **开发模式**：改前端只走 Vite(:5173)，**不构建正式包**（见 AGENTS.md 隔离规则）。
- **不新增依赖**：用现有 Vue3 + Element Plus + 自建 `ui.css` 组件层。
- **可验收**：每项改完用 Playwright 真机截图 + 与改动前对比，截图存 `logo-gen/shots/`。
- **数据字段**：所有展示字段必须来自真实 API，拿不到的（如播放量）**删掉而不是造假**。

## 补充修复（控件一致性审查，2026-10-10 下午）

用户在真机验收时反馈「开关/按钮看着奇怪、割裂」。真机逐页扫描后确认根因是
**两套组件体系并存 + 部分自建类只有 DesignPreview 的 scoped 样式**：

- **裸奔控件**：`.ui-chip` / `.ui-chips` / `.ui-icon-btn` 只在 `DesignPreview.vue`
  的 scoped 样式里有定义，关注列表页直接使用 → 渲染成浏览器默认灰按钮
  （`rgb(239,239,239)` + `outset` 边框）。已把这几个类补进全局 `styles/ui.css`。
- **按钮两套外观**：`ui-btn` 是 V3 硬边+偏移阴影，`el-button` 被 Element 默认样式
  覆盖成平板圆角。已在 `ui.css` 给 `.el-button` 补 V3 皮肤，与 `ui-btn` 对齐。
- **开关两套形状**：列表用 `.ui-switch`（硬编码 999px 胶囊）、表单用 `.el-switch`
  （方角）；V3 是 0 圆角主题。已让两者都跟随 `--radius-pill`，并统一轨道 36×20、
  手柄 14px；`Crawl.vue` 里重复的 `.ui-switch` scoped 定义已删除。
- **筛选条高度参差**：素材库分段控件 35px vs 下拉框 24px。已统一到 32px。
- **任务标题过长**：处理队列 `.pq-target` 原为 `ellipsis` 单行截断（与「详细信息
  必须展示完全」冲突），已改为换行完整显示。

真机扫描结果（Playwright，逐页 `overview/assets/pipeline/accounts/crawl/followed-creators/ai/system`）：
裸奔控件 `0`；开关轨道/手柄圆角一致；筛选条内控件等高；无文字溢出/重叠/裁切。
审查截图：`logo-gen/shots/audit/`。

## 3. 登录页文案草案（T2）

- 主标语：**把收藏夹，变成真正用得上个人素材库**
- 副标语：收藏从「存了就忘」到「随时能翻、能用、能改写」
- 三条价值点（对应产品真实能力，不夸大）：
  1. 多平台收藏自动归集：B站 / 抖音 / 小红书 / 快手 / 知乎 / 公众号
  2. 下载即转文字，可搜索可引用（本地 Whisper）
  3. AI 判类 + 爆款拆解，直接给出「为什么火、怎么复用」

## 4. 风险与注意

- **不改后端契约**：除非 T5 确需补字段（如 `created_at`），否则只动前端。
- **不乱编数据**：播放量删掉；指标拿不到就不显示。
- **登录页插画要克制**：product register 不主张营销化，插画服务于「一眼懂产品」。
- **性能**：不引入大图；生图资产压到合适尺寸再入 `web/public`。
