# 前端 UI/UX 调整 + 账户级存储布局（设计）

日期：2026-10-09 ｜ 分支：`feat/uiux-and-storage-layout`

## 目标

一次前端交互与信息密度调整，外加把「文件路径」从半成品模板补成一套完整、
清晰的账户级存储逻辑。共 5 块：

1. 总览去掉虚荣指标，换成可行动信息；
2. 关注列表卡片补边界线与显眼的同步开关；
3. 自动分析 / 自动转录做成设置弹窗里的显式开关；
4. 素材库把播放 / 阅读收敛到封面点击，已加工内容可重新加工；
5. 账户级存储目录：每个账户可单独指定根目录或共用，前端交互清晰可见。

## 1. 总览指标带

- 移除 `总播放 / 总点赞` 两张卡（含评论 / 收藏脚注）。
- 第二排改为四个可行动信号，全部来自 `/api/dashboard/summary` 既有字段：
  - 今日入库（近 7 天）
  - 已转录（已理解）
  - 已判类（未判类 · 占比）
  - 账号状态（在线 / 异常）
- 各平台明细表去掉 `播放 / 点赞` 两列，保留 平台 / 素材 / 视频 / 文章 / 占用。
- 热门 Top（按单条作品播放排名）保留，它是可行动信号，不是累计虚荣值。

## 2. 关注列表卡片

- 每张卡加真实边界线 `1px solid var(--ink)` + hover 抬升，和账号卡片一致。
- 同步开关从卡片底部提到**卡片头部右上角**，带状态文案（同步中 / 已暂停）；
  底部只保留 全量 / 仅收藏 与 历史 / 设置 / 移除。
- 设置弹窗分节：基本信息 · 同步 · 下载 · 加工。

## 3. 自动分析 / 自动转录

- 系统设置 → 视频理解新增两个全局默认：`自动转录新素材`、`自动视频理解新素材`
  （KV：`process_auto_transcribe` / `process_auto_analyze`）。
- 订阅设置弹窗新增两个同名开关（模型列 `auto_transcribe` / `auto_analyze`）。
  订阅级开关是显式 opt-in，命中后绕过热度门控直接入队。
- 既有「热度门控自动升高级档」逻辑不变。

## 4. 素材库交互

- 点封面即开始：视频 → 播放器，文章 → 阅读视图。封面 hover 显示 ▶ 播放 / 阅读提示。
- 底部状态按钮按状态切换：
  - 未转录 / 失败 → `转录`；已完成 → `重新转录`（带 已转录 徽标）。
  - 未分析 / 失败 → `分析`；已完成 → `重新分析`（带 已分析 徽标）。
- 移除 body 里重复的 播放 / 阅读 按钮，详情 / 转录 / 分析 留在底部操作区。

## 5. 账户级存储布局

物理路径 = `storage_root.path` + `relative_path`；`relative_path` 由模板渲染。

- `platform_account` 新增 `storage_root_id`（可空 = 用默认根）。两个账户可共用同一根，
  也可各指一个，均合法。
- 子目录模板新增 `{account}` token，默认 `{platform}/{account}/{creator}/{date}`。
- 账户中心卡片显示「存储位置」，并提供「设置目录」入口。
- 关注列表设置弹窗：根目录选择（继承账号 / 指定根目录）+ 子目录模板输入 + **实时路径预览**。
- 后端：下载处理器不再硬编码默认根，改为「账号根 + 订阅模板」在素材创建时解析。

红线遵守：路径仍为 `storage_root + relative_path`；外部 API 不接受绝对路径；
`reject_absolute` 校验保留。
